⬇ Paste & Download (Home Page)

This is the home screen, and the fastest way to download anything — no searching needed if you already have the link.

  • Paste a YouTube, Instagram, TikTok, Twitter/X, Facebook, Vimeo, Dailymotion, Reddit or Loom link straight into the box
  • Choose 📹 Video or 🎵 Audio
  • For video: pick a quality (1080p HD down to 360p) and a format (MP4, MKV, WEBM, MOV, AVI)
  • Hit the download button — the 🔔 bell in the header starts tracking it immediately
  • Every supported platform is listed right on this page so you always know what's covered
Paste any supported link, choose type/quality/format, and download
🔍 Search & Download

Search YouTube by keyword, play a result directly, and download it from there. You can also paste a Reddit, Instagram or Twitter/X link straight in to download it.

  • YouTube search — up to 40 results, with thumbnail/views/duration
  • Clicking a result plays the video instantly, with channel/views shown
  • A live audio waveform and word-by-word transcript appear as soon as it plays (in whatever language is spoken)
  • Platform tabs — YouTube, Reddit, Instagram, Twitter/X
  • A "Download" button right on every result in the list
Search & Download page — a video playing, results alongside it
💬 Playground Query (AI Assistant)

Ask the PastePro Assistant anything — a ChatGPT-style chat experience, with past chats saved in the sidebar.

  • Chat History — rename or delete past chats (with a confirmation popup)
  • Attach up to 5 files at once — image, video, PDF, DOCX, XLSX, PPTX, MD, HTML, ODT, RTF, EPUB, TXT all supported
  • The AI can "see" images (vision model), and reads doc/PDF/spreadsheet content to answer questions about them
  • Click any attached (or AI-generated) file to open it in a full-screen "canvas" viewer — images/videos/PDFs render directly, DOCX/XLSX/PPTX show their extracted text/table/slides
  • Ask the AI to build a website and its HTML reply gets Code / Preview tabs — a real live preview of the page, plus "open in a new tab" and "download the code"
  • Ask for a PDF, Word, Excel or PowerPoint file and the AI generates the real file — click "Generate & Preview" and it opens right in the canvas, with a Download button
  • Any other code (Python, JS, CSS, JSON, etc.) also gets a one-click Download button with the right file extension
  • Replies render tables, code blocks and bullet points properly formatted
  • Copy / Edit / Regenerate on every message

🎬 Video Editor

Upload any video and edit it directly — trim, add effects, animate it, and overlay text — all in one tabbed studio, then download the result.

  • Trim & Speed — cut a start/end range, and play it back from 0.5x to 2x
  • Audio — noise reduction (removes background hiss) and a volume slider
  • Effects — B&W, Sepia, Vignette, Blur, Sharpen filters, plus Brightness/Contrast/Saturation sliders
  • Animation — Fade In and Fade Out
  • Text overlay — your own caption, with font, size, color, position and an optional background box
  • Every option can be combined in a single edit — the result plays right there with a direct download link

⬇ Download Ready Page

This page appears the moment a download finishes.

  • Live audio waveform — appears instantly as soon as the video/audio plays, no waiting
  • Word-by-word transcript — the spoken text stays synced and highlighted as it plays
  • Convert to another format in one click (MP3, M4A, WAV, FLAC, OPUS or MP4, MKV, WEBM, MOV, AVI)
  • Direct download URL — copy it into IDM, a download manager, or anywhere else
  • The 🔔 bell icon in the header tracks every download's progress — see the Notifications section below
Waveform + live transcript + convert options + direct download URL
🔔 Notifications

The bell icon in the header tracks every download from the moment you click the download button — you don't have to stay on the Download Ready page to watch it finish.

  • Shows up the instant a download starts — with the platform (YouTube/Instagram/TikTok/etc.), quality and format
  • Live progress percentage while it's downloading, then Done, Failed or Cancelled once it finishes
  • A red dot on the bell marks anything you haven't seen yet
  • Keeps updating even if you switch to another page — it polls the server directly, independent of the page you're on
  • Dismiss a single notification with ✕, or clear everything with Clear All
  • View All jumps straight to Settings → Recent Downloads for the full history
