  • Any other code (Python, JS, CSS, JSON, etc.) also gets a one-click Download button with the right file extension
  • Replies render tables, code blocks and bullet points properly formatted
  • Copy / Edit / Regenerate on every message

📄 File Converter

Type text or upload images, and turn them into a real, downloadable document — no OCR, no text extraction for images, the picture goes straight into the file exactly as it looks.

  • Text mode — write (or paste) content with #/## headings, - bullets and **bold**, then generate a PDF, Word, PowerPoint, Excel, TXT, Markdown or RTF file
  • Image mode — upload one or more PNG/JPEG images at once; each one drops straight onto its own PDF page, Word paragraph, or PowerPoint slide, exactly as uploaded (iLovePDF-style "image to file")
  • Image mode only offers PDF, Word and PowerPoint as targets — Excel/TXT/Markdown/RTF can't hold a raw image, so those options hide automatically in that mode
  • A live percentage shows while the file is being generated, especially useful with several images at once
  • The finished file opens straight in the "canvas" viewer, with a Download button right there

🧰 PDF Tools

A full iLovePDF-style toolset — 31 tools across Organize, Optimize, Convert, Edit, PDF Security and PDF Intelligence, filterable by category. Every tool shows a live progress percentage while it works, and opens the result straight in the canvas viewer (ZIP-producing tools download directly instead).

  • Organize: Merge PDF (combine files in upload order) · Split PDF (every page → its own file, as a ZIP) · JPG to PDF (one or more images → one PDF, each on its own page) · Scan to PDF (same, with camera capture on mobile) · Organize PDF (thumbnail preview of every page — reorder with ↑/↓, delete any page, then rebuild) · Crop PDF (independent top/bottom/left/right margin sliders, applied to every page)
  • Optimize: Compress PDF (real before/after size shown, no exaggerated claims) · Repair PDF (best-effort fix for a damaged/corrupt file) · OCR PDF (for scanned/image-only PDFs with no text layer — rasterizes each page and runs it through the vision AI, producing a Word document)
  • Convert: PDF ↔ Word, PowerPoint and Excel in both directions · PDF to JPG (every page → a JPG, as a ZIP) · HTML to PDF (paste a URL to fetch and print it, or paste raw HTML directly) · PDF to Markdown (each page becomes a `## Page N` section — handy for notes or feeding into an LLM)
  • Edit: Edit PDF (click "Text Daalo"/"Image Daalo" then click any page to drop it there; drag to reposition, resize images, change text font size/color inline) · Watermark (your text stamped on every page — text, opacity, rotation, size and color are all adjustable) · Rotate PDF (90°/180°/270°, applied to every page) · Page Numbers (position and starting number configurable) · Compare PDF (upload two PDFs, see a line-by-line diff per page — added lines in green, removed in red) · PDF Forms (auto-detects existing fillable fields and builds a form to fill them; if a PDF has none, click anywhere on a page to add a brand-new fillable text field instead)
  • PDF Security: Protect PDF (add a password) · Unlock PDF (remove one, if you know it) · Sign PDF (draw a signature on a pad, then place/drag/resize it on any page — it's really just the Edit PDF image-overlay flow under the hood) · Redact PDF (click-drag a box over anything sensitive — the whole page is rasterized to an image with that area blacked out, so the underlying text is gone for good, not just hidden under a shape)
  • PDF Intelligence: AI Summarizer (a concise summary + key bullet points, shown right on the page — no file to download) · Translate PDF (AI-translated into one of 10 languages, delivered as a Word document)
  • A few things are honestly scoped rather than faked: PDF to PDF/A is disclosed as a best-effort structural cleanup, not a certified ISO PDF/A conversion; OCR PDF produces an editable Word doc rather than an invisibly-searchable PDF, since that needs word-level bounding boxes a plain-text AI response doesn't provide; Translate PDF outputs a clean new document rather than claiming to preserve the original's exact layout, since reflowing translated text into the same space reliably isn't realistic

🔔 Notifications

The bell icon in the header tracks every download from the moment you click the download button — you don't have to stay on the Download Ready page to watch it finish.

  • Shows up the instant a download starts — with the platform (YouTube/Instagram/TikTok/etc.), quality and format
  • Live progress percentage while it's downloading, then Done, Failed or Cancelled once it finishes
  • A red dot on the bell marks anything you haven't seen yet
  • Keeps updating even if you switch to another page — it polls the server directly, independent of the page you're on
  • Dismiss a single notification with ✕, or clear everything with Clear All
  • View All jumps straight to Settings → Recent Downloads for the full history
